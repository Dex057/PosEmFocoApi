# 📊 Camada DAO (Data Access Objects)\n\nGuia técnico sobre como os dados são acessados e manipulados no banco de dados.\n\n## 🎯 O que é DAO?\n\nDAO = Data Access Object\n\nPatrão que **isola acesso ao banco de dados** do resto da aplicação.\n\n```\n┌─────────────┐\n│   Services  │  (lógica de negócio)\n└──────┬──────┘\n       │\n       ↓\n┌─────────────┐\n│    DAOs     │  (acesso ao BD)\n└──────┬──────┘\n       ↓\n┌─────────────┐\n│  Banco Dados│  (postgresql)\n└─────────────┘\n```\n\n**Benefício:** Se trocar banco de dados (PostgreSQL → MySQL), só muda DAO.\n\n---\n\n## 📁 DAOs Disponíveis\n\n### 1. **usuario_dao.py**\n\nGerencia tudo relacionado a usuários.\n\n```python\n# Localização\napp/dao/usuario_dao.py\n```\n\n#### Métodos\n\n| Método | Descrição |\n|--------|----------|\n| `buscar_por_email(email)` | Procura usuário por email |\n| `buscar_por_id(id)` | Procura usuário por ID |\n| `salvar(usuario)` | Insere novo usuário |\n| `atualizar(usuario)` | Modifica usuário existente |\n| `deletar(id)` | Remove usuário |\n| `listar_todos()` | Retorna todos os usuários |\n\n#### Exemplo\n\n```python\nfrom app.dao.usuario_dao import UsuarioDAO\nfrom app.models.usuario import Usuario\n\n# Criar novo usuário\nnovo_usuario = Usuario(\n    nome=\"João Silva\",\n    email=\"joao@example.com\",\n    senha_hash=\"bcrypt_hash_aqui\"\n)\n\ndao = UsuarioDAO()\ndao.salvar(novo_usuario)  # Insere no BD\n\n# Buscar usuário\nusuario = dao.buscar_por_email(\"joao@example.com\")\nprint(usuario.nome)  # \"João Silva\"\n```\n\n---\n\n### 2. **interesse_dao.py**\n\nGerencia palavras-chave que o usuário quer acompanhar.\n\n```python\n# Localização\napp/dao/interesse_dao.py\n```\n\n#### Métodos\n\n| Método | Descrição |\n|--------|----------|\n| `salvar_lista(usuario_id, palavras)` | Salva múltiplas palavras |\n| `buscar_por_usuario(usuario_id)` | Retorna palavras do usuário |\n| `deletar_por_usuario(usuario_id)` | Remove todas as palavras |\n| `deletar_palavra(usuario_id, palavra)` | Remove uma palavra |\n\n#### Exemplo\n\n```python\nfrom app.dao.interesse_dao import InteresseDAO\n\ndao = InteresseDAO()\n\n# Usuário quer receber notificações de edital com estas palavras:\npalavras = [\"Mestrado\", \"Computação\", \"UFMG\"]\n\n# Salvar no BD\ndao.salvar_lista(usuario_id=1, palavras=palavras)\n\n# Depois, buscar o que ele quer acompanhar\ninteresses = dao.buscar_por_usuario(usuario_id=1)\nprint(interesses)  # [\"Mestrado\", \"Computação\", \"UFMG\"]\n```\n\n#### Implementação\n\n```python\ndef salvar_lista(self, usuario_id: int, palavras_chave: list):\n    \"\"\"\n    Salva várias palavras de uma vez (bulk insert)\n    \"\"\"\n    try:\n        # Preparar dados\n        dados = [\n            (usuario_id, palavra.strip().upper())\n            for palavra in palavras_chave\n        ]\n        \n        # Executar INSERT de múltiplas linhas\n        self.cursor.executemany(\n            \"INSERT INTO interesses (usuario_id, palavra_chave) VALUES (%s, %s)\",\n            dados\n        )\n        \n        self.conexao.commit()  # Confirmar\n        \n    except Exception as e:\n        self.conexao.rollback()  # Desfazer tudo se erro\n        raise Exception(f\"Erro ao salvar interesses: {str(e)}\")\n```\n\n**Por que `executemany()`?**\n- Mais rápido que 10 INSERT individuais\n- Tudo fica como \"transaction\" (tudo ou nada)\n- Se erro no meio, desfaz tudo com `rollback()`\n\n---\n\n### 3. **edital_dao.py**\n\nGerencia os editais descobertos pelo scraper.\n\n```python\n# Localização\napp/dao/edital_dao.py\n```\n\n#### Métodos\n\n| Método | Descrição |\n|--------|----------|\n| `salvar(edital)` | Insere novo edital |\n| `buscar_por_id(id)` | Procura edital por ID |\n| `buscar_por_usuario(usuario_id)` | Editais que combinam com interesses do usuário |\n| `listar_novos(dias)` | Editais dos últimos N dias |\n| `marcar_como_notificado(edital_id)` | Marca que usuário foi avisado |\n| `verificar_duplicado(url)` | Evita salvar edital 2x |\n\n#### Exemplo\n\n```python\nfrom app.dao.edital_dao import EditalDAO\nfrom app.models.edital import Edital\nfrom datetime import datetime\n\ndao = EditalDAO()\n\n# Scraper descobriu um edital\nnovo_edital = Edital(\n    titulo=\"Mestrado em Computação - UFMG 2026\",\n    url=\"https://...\",\n    descricao=\"Edital para seleção de...\",\n    data_publicacao=datetime.now(),\n    instituicao=\"UFMG\",\n    link_edital=\"https://site.ufmg.br/edital/...\"\n)\n\n# Verificar se já existe\nif not dao.verificar_duplicado(novo_edital.url):\n    dao.salvar(novo_edital)  # Salvar\n    \n# Buscar editais para um usuário\neditais_relevantes = dao.buscar_por_usuario(usuario_id=1)\nfor edital in editais_relevantes:\n    print(f\"{edital.titulo} - {edital.instituicao}\")\n```\n\n---\n\n## 🔄 Fluxo Completo: Usuário Recebe Notificação\n\n```\n1. Usuário Faz Login\n   └─ usuario_dao.buscar_por_email()\n   └─ Retorna: id=1, nome=\"João\"\n\n2. Usuário Define Interesses\n   └─ interesse_dao.salvar_lista(usuario_id=1, [\"Mestrado\", \"UFMG\"])\n   └─ Salva em BD\n\n3. Scraper Encontra Edital\n   └─ edital_dao.salvar(novo_edital)\n   └─ Salva em BD\n\n4. Sistema Processa Notificações\n   ├─ Busca todos os usuários\n   ├─ Para cada usuário:\n   │  ├─ interesse_dao.buscar_por_usuario(usuario_id)\n   │  └─ Pega: [\"Mestrado\", \"UFMG\"]\n   │\n   ├─ Procura editais que combinam\n   │  └─ edital_dao.buscar_por_usuario(usuario_id)\n   │\n   └─ Se encontrou:\n      ├─ Envia email\n      └─ edital_dao.marcar_como_notificado(edital_id)\n```\n\n---\n\n## 🛡️ Tratamento de Erros no DAO\n\n```python\ntry:\n    # Tentar fazer algo\n    dao.salvar_lista(usuario_id, palavras)\n    \nexcept IntegrityError:\n    # Erro: Violação de constraint (ex: email duplicado)\n    print(\"Email já cadastrado!\")\n    \nexcept Exception as e:\n    # Qualquer outro erro\n    print(f\"Erro desconhecido: {e}\")\n```\n\n### Erros Comuns\n\n| Erro | Causa | Solução |\n|------|-------|----------|\n| `IntegrityError` | Email/palavra duplicada | Validar antes |\n| `OperationalError` | BD desconectado | Reconectar |\n| `ProgrammingError` | SQL inválido | Revisar query |\n| `DataError` | Tipo de dado errado | Converter tipo |\n\n---\n\n## 📝 Boas Práticas\n\n### ✅ Faça\n\n```python\n# ✅ Usar executemany() para múltiplas inserções\ndao.cursor.executemany(\n    \"INSERT INTO tabela (col1, col2) VALUES (%s, %s)\",\n    [(val1, val2), (val3, val4)]\n)\n\n# ✅ Usar prepared statements (evita SQL injection)\ndao.cursor.execute(\n    \"SELECT * FROM usuarios WHERE email = %s\",  # %s = placeholder\n    (email,)  # Valor seguro aqui\n)\n\n# ✅ Commit quando modificar\nself.conexao.commit()\n\n# ✅ Rollback se erro\nself.conexao.rollback()\n```\n\n### ❌ Não Faça\n\n```python\n# ❌ SQL injection (PERIGO!)\ndao.cursor.execute(f\"SELECT * FROM usuarios WHERE email = '{email}'\")\n\n# ❌ Inserções sem commit\ndao.cursor.execute(\"INSERT INTO...\")\n# Dados não são salvos!\n\n# ❌ Sem tratamento de erro\ndao.salvar(usuario)  # Pode quebrar sem avisar\n```\n\n---\n\n## 🔍 Debugging\n\n### Verificar Dados no BD\n\n```bash\n# Conectar ao PostgreSQL\npsql -U postgres -d pos_em_foco\n\n# Ver usuários\nSELECT id, nome, email FROM usuarios;\n\n# Ver interesses\nSELECT * FROM interesses WHERE usuario_id = 1;\n\n# Ver editais\nSELECT titulo, instituicao, data_publicacao FROM editais;\n```\n\n### Log de SQL\n\n```python\n# No DAO, antes de executar:\nprint(f\"Executando: {sql_query}\")\nprint(f\"Com dados: {params}\")\n\n# Depois execute\nself.cursor.execute(sql_query, params)\n```\n\n---\n\n## 📚 Próximos Passos\n\n- [Models](models.md) - Estrutura de dados\n- [Database](../arquitetura/banco-dados.md) - Schema completo\n- [Services](../componentes/scraper.md) - Quem usa os DAOs\n\n---\n\n**Versão:** 1.0.0 | **Última atualização:** 25/01/2026\n"
