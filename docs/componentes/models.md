# 📦 Models (Estrutura de Dados)\n\nDocumentação das estruturas de dados usadas na aplicação.\n\n## 🎯 O que são Models?\n\nModels = Classes Python que representam dados\n\n- Definem a **forma** dos dados\n- Validam tipos\n- Servem como documentação viva\n\n```\n┌──────────────┐\n│   API Entry  │  (recebe JSON)\n└──────┬───────┘\n       │\n       ↓ (valida com Pydantic)\n       \n┌──────────────┐\n│    Model     │  (usuário, edital, interesse)\n└──────┬───────┘\n       │\n       ↓ (passa para service)\n       \n┌──────────────┐\n│   Service    │  (processa lógica)\n└──────────────┘\n```\n\n---\n\n## 👤 Model: Usuario\n\n**Arquivo:** `app/models/usuario.py`\n\n### Definição\n\n```python\nfrom pydantic import BaseModel, EmailStr, Field\nfrom datetime import datetime\n\nclass Usuario(BaseModel):\n    \"\"\"Representa um usuário cadastrado\"\"\"\n    \n    id: int | None = None  # None quando criando novo\n    nome: str = Field(..., min_length=3, max_length=100)\n    email: EmailStr  # Valida formato de email\n    senha_hash: str  # Nunca armazenar senha plana!\n    data_criacao: datetime = Field(default_factory=datetime.now)\n    ativo: bool = True\n    \n    class Config:\n        schema_extra = {\n            \"example\": {\n                \"id\": 1,\n                \"nome\": \"João Silva\",\n                \"email\": \"joao@example.com\",\n                \"ativo\": True\n            }\n        }\n```\n\n### Usando\n\n```python\nfrom app.models.usuario import Usuario\n\n# Criar novo usuário\nnovo_usuario = Usuario(\n    nome=\"Maria\",\n    email=\"maria@example.com\",\n    senha_hash=\"$2b$12$hash_bcrypt_aqui\"\n)\n\n# Acessar campos\nprint(novo_usuario.nome)  # \"Maria\"\nprint(novo_usuario.email)  # \"maria@example.com\"\n\n# Converter para dict (para BD)\nuser_dict = novo_usuario.dict()\n# {\"nome\": \"Maria\", \"email\": \"maria@example.com\", ...}\n\n# Converter para JSON\nuser_json = novo_usuario.json()\n# '{\"nome\": \"Maria\", \"email\": \"maria@example.com\", ...}'\n```\n\n### Validações Automáticas\n\n```python\n# ✅ OK\nusuario = Usuario(\n    nome=\"João\",\n    email=\"joao@gmail.com\",\n    senha_hash=\"hash\"\n)\n\n# ❌ ERRO: nome muito curto\ntry:\n    usuario = Usuario(\n        nome=\"Jo\",  # Mínimo 3 caracteres\n        email=\"joao@gmail.com\",\n        senha_hash=\"hash\"\n    )\nexcept ValidationError as e:\n    print(e)  # \"String should have at least 3 characters\"\n\n# ❌ ERRO: email inválido\ntry:\n    usuario = Usuario(\n        nome=\"João\",\n        email=\"nao_eh_email\",  # Sem @\n        senha_hash=\"hash\"\n    )\nexcept ValidationError as e:\n    print(e)  # \"Invalid email format\"\n```\n\n---\n\n## 📌 Model: Interesse\n\nRepresenta uma palavra-chave que o usuário monitora.\n\n```python\nfrom pydantic import BaseModel, Field\n\nclass Interesse(BaseModel):\n    \"\"\"Palavra-chave que usuário quer acompanhar\"\"\"\n    \n    id: int | None = None\n    usuario_id: int  # Qual usuário é dono\n    palavra_chave: str = Field(..., min_length=2, max_length=50)\n    data_criacao: datetime = Field(default_factory=datetime.now)\n    \n    class Config:\n        schema_extra = {\n            \"example\": {\n                \"usuario_id\": 1,\n                \"palavra_chave\": \"Mestrado em Computação\"\n            }\n        }\n```\n\n### Usando\n\n```python\nfrom app.models.interesse import Interesse\n\n# Criar interesse\ninteresse = Interesse(\n    usuario_id=1,\n    palavra_chave=\"Mestrado\"\n)\n\n# Filtrar depois\nif \"mestrado\" in edital.descricao.lower():\n    # Este edital é relevante!\n    pass\n```\n\n---\n\n## 📜 Model: Edital\n\nRepresenta um edital descoberto pelo scraper.\n\n```python\nfrom pydantic import BaseModel, HttpUrl\nfrom datetime import datetime\nfrom typing import Optional\n\nclass Edital(BaseModel):\n    \"\"\"Representa um edital de seleção\"\"\"\n    \n    id: int | None = None\n    titulo: str  # Ex: \"Mestrado em Computação 2026\"\n    url: HttpUrl  # URL onde scraper encontrou\n    descricao: str\n    instituicao: str  # Ex: \"UFMG\"\n    link_edital: HttpUrl | None = None  # Link direto do edital\n    \n    data_publicacao: datetime\n    data_descoberta: datetime = Field(default_factory=datetime.now)\n    \n    # Para rastrear notificações\n    notificado: bool = False\n    data_notificacao: Optional[datetime] = None\n    \n    class Config:\n        schema_extra = {\n            \"example\": {\n                \"titulo\": \"Mestrado em Ciência da Computação - UFMG 2026\",\n                \"url\": \"https://www.ufmg.br/edital/mestrado-cc-2026\",\n                \"instituicao\": \"UFMG\",\n                \"descricao\": \"Seleção para ingresso em...\"\n            }\n        }\n```\n\n### Usando\n\n```python\nfrom app.models.edital import Edital\nfrom datetime import datetime\n\nedital = Edital(\n    titulo=\"Mestrado em Computação - UFMG 2026\",\n    url=\"https://...\",\n    descricao=\"Seleção para mestrado...\",\n    instituicao=\"UFMG\",\n    data_publicacao=datetime.now()\n)\n\n# Verificar se deve notificar\nif edital.descricao and \"computação\" in edital.descricao.lower():\n    print(\"✉️ Enviar email!\")\n```\n\n---\n\n## 🔀 Requests (Dados que chegam da API)\n\nThese são Models que recebem dados da API.\n\n### CadastroRequest\n\n```python\nclass CadastroRequest(BaseModel):\n    \"\"\"Dados para criar novo usuário\"\"\"\n    \n    nome: str = Field(..., min_length=3)\n    email: EmailStr\n    senha: str = Field(..., min_length=8)  # Senha crua (não hash)\n    interesses: list[str] = []  # Palavras-chave iniciais\n    \n    class Config:\n        schema_extra = {\n            \"example\": {\n                \"nome\": \"João Silva\",\n                \"email\": \"joao@example.com\",\n                \"senha\": \"Aluno@2026\",\n                \"interesses\": [\"Mestrado\", \"Computação\", \"UFMG\"]\n            }\n        }\n```\n\n### LoginRequest\n\n```python\nclass LoginRequest(BaseModel):\n    \"\"\"Dados para fazer login\"\"\"\n    \n    email: EmailStr\n    senha: str\n    \n    class Config:\n        schema_extra = {\n            \"example\": {\n                \"email\": \"joao@example.com\",\n                \"senha\": \"Aluno@2026\"\n            }\n        }\n```\n\n### No servidor\n\n```python\nfrom fastapi import FastAPI\nfrom app.models.usuario import CadastroRequest\n\napp = FastAPI()\n\n@app.post(\"/cadastro\")\nasync def cadastrar(dados: CadastroRequest):\n    \"\"\"\n    Pydantic valida automaticamente:\n    - nome tem mínimo 3 chars\n    - email é formato válido\n    - senha tem mínimo 8 chars\n    - interesses é uma list\n    \"\"\"\n    \n    # Se chegou aqui, dados são válidos!\n    print(dados.nome)  # \"João Silva\"\n    print(dados.email)  # \"joao@example.com\"\n    print(dados.interesses)  # [\"Mestrado\", ...]\n```\n\n---\n\n## 🔄 Responses (Dados que saem da API)\n\n### UsuarioResponse\n\n```python\nclass UsuarioResponse(BaseModel):\n    \"\"\"Dados retornados ao fazer login\"\"\"\n    \n    id: int\n    nome: str\n    email: str\n    data_criacao: datetime\n    interesses: list[str] = []  # Inclui interesses do usuário\n    \n    class Config:\n        schema_extra = {\n            \"example\": {\n                \"id\": 1,\n                \"nome\": \"João\",\n                \"email\": \"joao@example.com\",\n                \"interesses\": [\"Mestrado\", \"UFMG\"]\n            }\n        }\n```\n\n### EditalResponse\n\n```python\nclass EditalResponse(BaseModel):\n    \"\"\"Edital para enviar ao cliente\"\"\"\n    \n    id: int\n    titulo: str\n    instituicao: str\n    descricao: str\n    url: str\n    link_edital: str | None\n    data_publicacao: datetime\n    motivo_notificacao: str  # Ex: \"Contém 'Mestrado'\"\n```\n\n### Usando no endpoint\n\n```python\n@app.get(\"/usuario/{usuario_id}\", response_model=UsuarioResponse)\nasync def get_usuario(usuario_id: int) -> UsuarioResponse:\n    \"\"\"\n    Retorna UsuarioResponse\n    - FastAPI valida response\n    - Se faltou campo, erro\n    - Se tipo errado, erro\n    \"\"\"\n    usuario = dao.buscar_por_id(usuario_id)\n    return UsuarioResponse(\n        id=usuario.id,\n        nome=usuario.nome,\n        email=usuario.email,\n        data_criacao=usuario.data_criacao,\n        interesses=dao.buscar_interesses(usuario_id)\n    )\n```\n\n---\n\n## 🛡️ Validações Customizadas\n\n```python\nfrom pydantic import validator, root_validator\n\nclass Usuario(BaseModel):\n    nome: str\n    email: str\n    senha: str\n    \n    @validator('nome')\n    def nome_valido(cls, v):\n        \"\"\"Validar nome customizado\"\"\"\n        if not v.replace(\" \", \"\").isalpha():\n            raise ValueError('Nome deve conter apenas letras')\n        return v.title()  # Converter para \"Title Case\"\n    \n    @validator('senha')\n    def senha_forte(cls, v):\n        \"\"\"Validar força de senha\"\"\"\n        if len(v) < 8:\n            raise ValueError('Senha deve ter mínimo 8 caracteres')\n        if not any(c.isupper() for c in v):\n            raise ValueError('Senha precisa de letra maiúscula')\n        return v\n```\n\n---\n\n## 🔍 Debug\n\n```python\n# Inspecionar dados recebidos\nuser_dict = usuario.dict()\nprint(user_dict)  #
